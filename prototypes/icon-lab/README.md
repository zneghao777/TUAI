# 天质 AI 动态图标实验室

独立的可交互设计样稿，包含 184 个现有目录图标与 28 个未来场景。
每个图标支持轻线、圆弧、切角、开线、等距五种纯线条风格，共 1,060 个版本。
常用图标逐项重绘圆弧／切角构型，其余目录按同一几何规则生成变体。
现有目录覆盖共享图形、代码及文档类型、权限、内联布局和运行状态；
统计包含兼容目录，并不表示每个图标都在当前页面可达。

## 运行

在仓库根目录执行以下命令。Node.js 与 npm 使用本机环境；依赖和锁文件
保留在这个目录，不改变主应用依赖。

```sh
npm --prefix prototypes/icon-lab ci --ignore-scripts
npm --prefix prototypes/icon-lab run dev
```

打开 [本机预览](http://127.0.0.1:4317/)。预览不连接业务 Host。

已选轻线细线版可在[聊天模拟](http://127.0.0.1:4317/chat)查看，图标库顶部也有入口。
按当前聊天页布局展示空白会话、文件回复和工具运行；普通图标跟随三种主题，
文件保持独立配色。输入、发送、模型和权限菜单仅改变本地示例状态。

## 查看与复用

顶部同时对照所选图标的五种风格，可同步重播；目录可以按分类、现有／未来和名称筛选。
悬停、聚焦、点击或重播触发动效，也可选择循环与静止。
支持 20／32／48 像素、0.5／1／1.5 倍速与系统减少动态效果。
绿色和晨曦使用项目已有强调色，纯白使用白底黑灰单色；晨曦保持仅浅色。
PDF 红、Word 蓝、表格绿、PPT 橙等文件类型不跟随主题色，深色仅调整亮度。
所有 SVG 图形均为细线，无填充、渐变或阴影；主体线宽 1.05～1.35。

- `src/catalog.ts`：语义 ID、原创 SVG 几何、部件动画及分类。
- `src/variants.ts`：独立造型、完整目录的几何规则与矢量线段字体。
- `src/palettes.ts`：主题强调色、文件类型色与导出默认颜色。
- `src/AnimatedIcon.tsx`：SVG + Framer Motion 渲染与静态 SVG 导出。
- `src/inventory.json`：从项目源码生成的共享目录、引用及内联来源。
- `src/source-map.ts`：内联图形映射，以及品牌和基础设施的保留理由。
- `src/App.tsx`：HeroUI 预览控件及筛选、检查器、下载行为。
- `src/chat/ChatPreview.tsx`：复用轻线组件的聊天模拟、示例交互与资源清理。
- `CHAT-PREVIEW.md`：聊天模拟的来源、范围与验收要求。

下载 SVG 是静态造型，动态效果由 React 组件提供；页面已明确标注。
下载清单包含设计 ID、中文名称、分类、来源与原组件名称。
SVG 不读取外部图片，也不依赖运行中的项目源码。笔画使用 `currentColor`；
独立下载文件用 `color` 属性保存当前默认色，内联接入时可由主题 CSS 覆盖。

生产接入须在选定风格后单独实施。正式图标组件、业务逻辑、品牌 Logo、
供应商／网站商标均未替换；文件类型使用统一文件外框与可识别缩写。

## 核验

在仓库根目录执行定向检查。来源扫描只处理源码，不读取运行数据或凭据。

```sh
npm --prefix prototypes/icon-lab run inventory
npm --prefix prototypes/icon-lab run check:coverage
npm --prefix prototypes/icon-lab run build
```

其余四套保留对比。本样稿完成不代表生产集成或整体应用验收完成。
