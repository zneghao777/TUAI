# 图标实验室设计与验收

这是独立的设计样稿，不改变产品的视觉规范或应用完成统计。

## 设计方向

2026-10-29 第二轮：用户反馈第一轮主要差异是颜色与填充，要求造型及动效
差异更明显，全部改为无填充线条；增加绿色、晨曦和纯白主题适配。
保留 212 个语义 ID 与来源映射，正式图标仍不接入。

- 轻线：原线性方案转为完全无填充，短位移与单笔描绘。
- 圆弧：气泡、圆形与胶囊轮廓；压缩、伸展与弹性回正。
- 切角：直角、折线和切角结构；部件从不同方向分段组装。
- 开线：开放轮廓与分离笔段；逐段游走描线。
- 等距：有侧面与连接边的空间线框；前后层展开、回合。

常用图标逐个重新绘制圆弧与切角语义构型，完整目录使用对应的几何规则扩展。
不是给原图形添加颜色滤镜；五种风格在同一主题下比较，所有 SVG 图形均无填充。
文件类型缩写也使用矢量线段字体。原双生／浮光的填充方向退出当前预览。

线条统一使用 `currentColor`，由 `--icon-stroke` 映射主题强调色。
绿色取正式主题 `#58786d`，晨曦取 `#155dfc`；纯白定义为白底、墨黑线条。
晨曦遵循正式产品当前仅支持浅色的约束；纯白是本实验室的单色设计候选。
导出 SVG 同样保留 `currentColor`，并用当前主题色作独立文件的默认颜色。

用户追加要求：线条稍细，文件类型使用独立配色。主体线宽为 1.05～1.35，
空间辅助线为 0.85；PDF 红、Word 蓝、Excel 绿、PPT 橙等文件语义色
不随绿色／晨曦／纯白切换。深色仅调整亮度，所有图形仍然无填充。

页面采用以图标为主的陈列台：顶部五套风格选择、主题色切换和同图标对照，
左侧分类、中间图标网格、右侧详情。小屏将详情放在列表之前，避免遮挡。
默认悬停、聚焦或点击播放，提供循环与静止模式；切出视口或页面隐藏停止运动。
不使用营销标语、背景装饰或大量说明性标签。

## 依赖与边界

独立目录 `prototypes/icon-lab`，通过 npm 在该目录安装，不改主项目锁文件。
读取源码生成静态来源清单；预览运行时不读取项目源码或业务数据。
Logo、供应商品牌、网站 favicon 不伪造，文件图标采用统一文件轮廓和类型缩写。

## 验收

- ICON-01：共享图标目录、代码文件类型、传统文件类型、权限和内联图形均有映射；
  列出兼容目录与实际源码引用，不宣称已完成运行时路径覆盖。
- ICON-02：212 个图标均有五种无填充线条样式；静止时轮廓不同，播放时轨迹不同。
- ICON-03：搜索、分类、现有／未来、大小、深浅色、播放模式、重播和下载可用。
- ICON-04：悬停与键盘、点击与触屏都可触发动效；减少动态效果时保持静止。
- ICON-05：桌面与 390px 无横向溢出，详情、过滤空状态和焦点可理解。
- ICON-06：独立类型检查和构建通过，正式应用入口与原图标实现无修改。
- ICON-07：绿色／晨曦／纯白切换会改变通用图标线条，SVG 不包含固定笔画颜色、
  填充、渐变或投影；静态导出与预览采用相同的变体几何与默认色。
- ICON-08：文件类型在三种主题下保持固定语义色，PDF 与 Word、Excel、PPT
  可通过颜色和类型缩写区分。
