# TZ-082：纯白默认主题验收

2026-10-29，在 macOS arm64、Node 26.8.1、Chrome 完成本机定向验收。
范围见[纯白主题需求](../specs/appendices/P2-纯白主题需求.md)。

## 实现与兼容

纯白扩展现有产品语义配色和 `ui-theme` 文档，没有新增偏好缓存或依赖。

- 新增 `white`，全新或空文档默认纯白浅色；设置按纯白、青绿、晨曦排序。
- 旧非空无 `palette` 文档只在内存中推断青绿，启动不改文件与修订号。
  显式青绿、晨曦、明暗和字体保持原值；下次主动保存才持久化推断结果。
- 新设置第一次只保存字体时也保存纯白，避免重启后被误认为旧记录。
- 纯白、晨曦选择时原子保存浅色；青绿原有三种明暗能力保持正常。
- 纯白画布与正文保持实白，侧栏 80%、输入框 90% 白色与 20px 模糊，
  菜单 97% 白色；设置内容区保持不透字，鼠标柔光收敛为中性低强度。
- HeroUI／DSH 共用语义变量；配色变化通过原主题覆盖接口重新呈现，
  浏览器 `theme-color` 与画布同步；旧覆盖层仍由同一所有者释放。
- 按钮名称、`aria-pressed`、保存中禁用和失败提示供用户及浏览器 Agent 使用。
