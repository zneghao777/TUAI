# TZ-076：简化聊天区验收

> 后续 TZ-078 根据用户纠正恢复了搜索、会话行归档按钮和菜单图标，并将删除确认改为原有弹窗样式。以下为 TZ-076 当时的历史验收，最新结果见总计划 RUN-20261029-P2-23。

本项按[简化聊天区需求](../specs/appendices/P2-简化聊天区需求.md)实施。当前记录本机 macOS／Chrome 与受控模型结果，不代表 Windows、Linux、移动实机、Electron 或真实供应商已验证。

## 实现

生产入口 `mountProductUi` 使用平铺聊天列表，保留 DSH Session／UiWorkspace 所有权。列表没有工作区分组、筛选、搜索、ID 复制、分叉和归档列表；对应搜索／添加目录／分叉快捷键不注册，回复末尾不提供分叉。保留置顶、重命名、归档和运行／待处理／未读完成状态。

新建仍由 `ManagedSessionController` 为每个 Session 创建独立目录。目录策略见需求附录；本机已观察到标准 `~/Library/Application Support/TIanZhiAi/data/workspaces/`，没有依赖项目源码目录。

删除使用 Host 存储域的独立持久标记，经原归档准入停止 Turn／Job／Subagent 并阻止后续步骤，发出原 Session removed 事件同步各 Client。统一 Gateway 生命周期准入覆盖所有者请求，列表／搜索／控制投影排除删除项；产物 HTTP 下载也拒绝已删除会话。删除保留工作区文件和底层恢复日志，界面不提供恢复。取消、提交中和失败都有真实状态。

权限目录和默认设置仅只读／完全权限，默认只读。旧 `workspace-write` 默认设置迁移为只读；旧 Session 在物化时收回该已移除模式，完全权限不自动增加。产品不默认挂载 Auto review，核心插件保留并独立测试。思考及普通／空白聊天占位文案统一，完成状态显式左对齐。

通用按钮复用 HeroUI 适配层；重命名用 Modal／Form／Input，删除用 AlertDialog。行菜单保留已有 Menu 的键盘遍历、Portal 和焦点处理，不重写专用菜单状态机。

手机宽度展开侧栏时，导航占满可用区域，聊天和右栏暂时隐藏，避免将输入框挤成窄条。打开会话后收起导航，恢复聊天宽度；手机端切换不沿用桌面的网格过渡。框架只增加语义布局标记，产品样式通过公开标记适配，不绑定编译后的类名。
