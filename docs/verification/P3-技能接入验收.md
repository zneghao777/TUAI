# P3 技能接入验收

2026-10-29。本轮范围为 TZ-031 的独立技能管理和 TZ-032 的技能页；
长期 Agent／群绑定、TaskExecution 及其他管理页面不在本轮范围。

## 实现

- 复用 DSH Skill 注册表契约和基线 tool-skill，保留唯一 Agent Loop。
- 个人技能目录使用独立 SQLite 业务库；版本内容不可覆盖，修改带 revision 校验。
- 支持 SKILL.md／目录导入、正文编辑、结构与声明依赖检查、启停及回滚。
- 会话回合冻结版本，实际加载记录版本摘要；停用阻止后续加载，历史记录不变。
- 配套资源存为包内字节；加载后生成当前会话工作区副本，支持既有脚本相对路径。
  复制不执行脚本，Shell 和文件操作保持原权限。资源工具支持按需读取 UTF-8 文件。
- 技能页复用项目 DSH Button／Modal 适配层和主题；仅新增技能页及输入框技能候选。

## 限制

结构检查不代表航班报价、网站操作或脚本业务行为经过验证。导入上限为 128 个
文件／2 MB；读取大于 128 KB 的文本资源需拆分，二进制资源可在页面下载。
个人范围为当前已认证单 Host 所有者；长期 Agent／群绑定和 P5 学习保持未实现。
已进入模型上下文的技能知识不能被停用操作撤回，后续工具权限仍在执行层检查。
