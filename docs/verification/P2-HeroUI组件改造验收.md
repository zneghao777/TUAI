# P2 HeroUI 组件改造验收

本记录覆盖 TZ-070～075 和 UI-HERO-01～10。使用当前代码与本轮实时页面，
不读取历史截图；原 TZ-022 验收记录保持不变。验收日期为 2026-10-29。
TZ-070～075 本机验收通过；平台和外部服务边界见文末。

## 本次交付

模型入口通过产品 Slot 替换呈现，继续使用 `ModelDirectory` 和 Session 投影，
与 `/model` 共用目录、选择、推理元数据和提交方法。按用户本轮补充，
弹层收窄至 272 px，降低字号、留白及阴影，去掉搜索框和管理入口；完整管理
从侧栏设置进入。滑杆显示提供商定义的等级，提交实际等级 ID，不把档位序号
当推理预算。拖动中连续跟随，松手以 160 ms 过渡吸附到最近档位，
只提交一次实际等级；方向键逐档切换，Home／End 到两端。支持无推理模型、提供商默认、非等距语义 ID、失败重试及会话隔离。

鼠标柔光通过 `requestAnimationFrame` 合并事件和平滑跟随，不触发 React 重渲染，
不参与命中测试。触屏、减少动态效果、失焦、页面隐藏和卸载会隐藏并取消动画。
浅深色语义变量同时映射 HeroUI 与 DSH，沿用原有外观偏好，不新增配色选择。

设置使用单一 Modal 和保留挂载的分类面板；提供商表单保留字段校验、版本号、
密钥遮蔽、真实连接测试和保存结果。重新加载配置保留编辑草稿，删除要求独立
AlertDialog 确认，忙碌时禁止关闭。修复嵌套 DSH 菜单的 Escape 竞态和外部点击；菜单 Portal 留在所属
Dialog 内，避免被 HeroUI 的窗口外禁用机制阻止点击。弹窗显式设置 data-shortcut-modal，
让既有快捷键系统识别前台弹窗，避免后台新建会话；草稿和刷新恢复已复验。开关和复选框保留可访问名称、悬停提示及禁用保护，
通过完整指针序列验证文字标签激活。

## 组件清单与保留理由

以下是实际生产路径，不将候选组件名称当作已接入证据。

| 区域                   | 实际组件与实现                                                             | 保留的专用逻辑                                                                 |
| ---------------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| 公共控件               | HeroUI Button、Input、Switch、Checkbox、Surface                            | 原生事件、属性、ref 由适配层保持；作用于导航、输入、工具、审批、队列与文件操作 |
| 模型弹层               | Popover、ListBox、Slider、Button、Spinner                                  | 共享目录、Session 投影和 Host 提交；无搜索框或管理入口                         |
| 设置与模型管理         | Modal、Tabs、Form、Input、Select、ListBox、AlertDialog                     | 草稿、版本冲突、凭据、忙碌状态、真实测试和删除语义                             |
| 会话与权限菜单         | Surface、ActionButton                                                      | 多级菜单、快捷键、原操作与权限确认；保留原 Menu 状态机                         |
| 对话与工具             | Button、ActionButton、Surface                                              | 流式合并、思考、步骤树、折叠、命令输出、终端和真实状态                         |
| 问题、审批、计划、附件 | Button、ActionButton、Checkbox、ProgressBar、Spinner                       | 请求身份、取消／过期、自由回答、收据、失败重试和队列编辑                       |
| 上下文                 | Meter、ActionButton                                                        | 真实容量及近似构成，保留近似标识；用量统计仍隐藏                               |
| 文件与产物             | ActionButton、Spinner、统一表面变量                                        | 文件树、鉴权下载、图片／PDF／表格等渲染，错误与重试                            |
| 编辑器与拖拽面板       | 保留 Lexical、Dockkit，外围操作用 ActionButton                             | IME、引用节点、拖拽、Tab 生命周期和预览保活不交给通用组件重做                  |
| 提示及安全弹窗         | 保留专用 Tooltip 与 DSH Modal 的焦点所有者，后者使用 Surface／ActionButton | 快捷键提示、裁剪、触摸固定提示及命令域保持；避免叠加第二套焦点管理             |

模型目录的“重新加载”还修复了一个共享对象层问题：RPC 成功但部分提供商失败时，
原缓存会一直返回失败快照。现在显式读取会重试有失败项的目录，并保留仍可用的
分组；恢复成功后继续缓存，重复并发读取共享同一请求。

## 性能与当前页面

在 Apple M5 Pro／macOS arm64／Chrome 1440×1000 上，一万条历史加载 50 页，
首屏 85 ms，点击至接受并绘制 1624 ms，页面 132,166 个节点。
通过原首屏 1 秒／输入绘制 2 秒门禁；不把浏览器自动化总耗时当作输入绘制延迟。
测量入口为 `history.spec.ts`，本轮输出为 `reports/p2/performance.json`。

当前浅／深色模型面板截图由 `heroui.spec.ts` 在 1440／390 px 视口生成，
输出为 `reports/p2/hero-{light,dark}-{1440,390}.png`；未用旧图作为验收依据。
P2 单元入口已纳入公共控件、快捷键、主题运行时和反馈套件，后续执行 `test:p2` 即覆盖。
原 DSH 全仓静态样式清单依赖未迁入的桌面、账户、插件页面，并固定原视觉约束，
没有加入本产品门禁；主题运行时、当前组件和本轮实页面验证分别覆盖本次范围。
React 19 的测试 ref 断言按节点参数核验，定时状态更新在 act 中刷新；断言内容不删减。
本轮模型／设置／柔光文件的机械检测无发现。来源检查覆盖 209 包、4,242 声明导入，许可检查 346 项。
31 个 React 消费者、16 个 React DOM 消费者分别解析到单一 19.2.9 实例。

或 Electron 实壳验收。本机静态构建保留现有 PDF／Excel 大 chunk 提示。
