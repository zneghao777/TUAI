## 从界面到真实执行

所有业务调用复用迁入的 Connection、Gateway、Typert 生成协议和 Session 对象。
React 通过订阅绑定读取领域事实；组件只保留草稿、选择、展开等交互状态。

| 页面操作                     | 协议与客户端对象                                            | Host、实际执行/持久化                                   | 回执和界面更新                                             | 主要验收                          |
| ---------------------------- | ----------------------------------------------------------- | ------------------------------------------------------- | ---------------------------------------------------------- | --------------------------------- |
| 登录、重连、切换 Host        | Connection generation、Gateway RPC/MUX、生成 codec          | Connection owner 认证、Peer Access、真实 WebSocket/HTTP | 新代次 baseline；旧回调失效；Host 隔离草稿                 | TZ-015；PROTO-07/08               |
| 新建/切换/重命名/派生会话    | Sessions/Manager/Session、retain/release                    | SessionController、JSONL、查询派生缓存                  | 实际 Session ID、历史清单与事件订阅                        | TZ-016；PROTO-01/05               |
| 输入、上传、排队、插话、停止 | Session prompt/requestId、file-upload、队列编辑/删除/cancel | 上传归档、输入收据、原 Agent Loop 和取消链              | 接受后收敛草稿；next-turn/next-step 投影；执行结束独立展示 | TZ-018；PROTO-01/02/09、UI-01     |
| 流式消息、工具详情和嵌套     | Projection/EventSource、Assistant attempt/revision/index    | 原工具 pipeline、真实文件读取/沙箱 Bash、JSONL 和 Spill | 临时流与持久事件归并；参数/命令/原始结果/错误可展开        | TZ-019；PROTO-03/04、UI-02/04     |
| 来源/产物/图片               | 原 Session 附件接口；platform.artifacts                     | 实际持久附件归属、当前会话 Spill；owner 鉴权下载        | 真实列表和文件响应；已清理明确失败                         | TZ-019；AUDIT-01/04               |
| 回答问题、批准/拒绝/取消     | 实际 Remote waterfall，按 Session/eventId/连接作用域关联    | UserQuestions/UserApproval，最终工具 guard 与超时取消   | Host 结束请求后撤下卡片；批准后另等真实工具结果            | TZ-020；PROTO-06、UI-03、AUDIT-02 |

| 文件选择/原生能力            | Node-free Platform、HostPath、受控 DesktopBridge            | Web 选择当前设备文件；原生适配只允许限定方法/授权路径   | Web 原生操作 unavailable；桥核对调用方/Host/代次/回执      | TZ-022；PROTO-08、UI-06           |

Host、原循环、工具权限、实际文件/进程和持久化；受控回答不进入正常启动组合。
测试不是用页面计时器或静态数组冒充执行。

## 运行与边界

安装和构建、真实模型配置、代理约束见 [README](../../README.md#web-工作区)。
后端同时托管生产 Web，`pnpm start:web` 默认 `127.0.0.1:3100`；先打开终端输出的
认证入口，再进入根地址。`pnpm dev:web` 用 Vite 开发服务器代理运行中的 Host。
`pnpm demo:p2` 明确启动受控模型、真实 Host 演示，默认 `127.0.0.1:3101`，退出清理临时数据。
认证链接包含凭证，不应提交、转发或写入截图/报告。

本次只读核对当前 Host 配置：没有 DeepSeek 的显式凭据引用，未读取或输出秘密值，
因此没有调用真实外部模型。也未验证公网远程部署、真实移动设备、Windows/Linux 安装，
或 Electron 窗口/真实 Preload/签名/打包。缺少这些证据不写成通过；它们不由受控模型和桥测试替代。
生产 PTC、TaskRuntime、多 Agent、浏览器接管、Skill/MCP 和计划通知仍在既定后续阶段。
Vite 提示约 980 KB 的单个 JS 分块较大（gzip 约 256 KB）；历史虚拟化和本机性能已测，
不声称完成所有设备/网络的性能优化。部分上游套件有 process exit listener/实验 API 警告，
专门的资源释放与进程退出测试已通过。
