# P1 核心迁移与验收

本记录说明 P1 的实际组合、来源差异和验证证据。进度统一保存在
[总开发计划](../../总开发计划与进度记录.md)，包和文件来源保存在
[M1/M2 迁移登记](../migration/M1-迁移登记.json)。

## 产品适配边界

迁入版本固定为 `22ddee3792402c3e70ec5f86a63c3e3e895a2f60`。
保留原 Agent Loop、Session 事件、工具执行和模型协议语义。

- 模型凭据仅通过 Host 配置中的显式环境引用解析；不自动发现 `.env`。
- 产品组合不创建或上传上游匿名用户身份。模型协议适配器保留显式身份钩子，
  产品 Provider 不提供它；其他协议字段保持来源行为。
- 模型路由使用迁入的 DeepSeek Messages Provider；验收使用本机受控 HTTP 服务，
  不将该结果写成真实外部模型测试。
- Agent Loop 和工具执行器在 TZ-008 作为重试测试依赖迁入；产品执行链在
  TZ-010 接通，不提前将测试依赖算作该任务完成。

## 构建、资源与本地差异

- 包间 JS 保留运行时外部引用；多入口使用共享分块，防止 `tools` 与 `tools/pipeline`
  产生两份服务身份。类型、源码所用子路径和运行入口统一核验。
- JSONL 迁移校验 Worker 保留上游的独立 CJS 闭包，Native 仍为外部模块；
  CJS 模块地址适配用于保持包版本归属查找。已加入 plain Node 的独立 Worker 测试。
- Native 源码、平台矩阵、BSD-3-Clause 许可和构建辅助均保留；
  macOS arm64 本机编译并验证 flock，其他架构仅保留来源，不声称安装成功。
- 子进程启动辅助、沙箱 runner、附件图像依赖和 JSONL 旧格式 fixture 已随来源登记。
  开发构建需要本机编译器及 Node 头文件；不能把 workspace 锁文件当成可分发安装包。
- `typert.*` 生成导出与连接传输留给 TZ-015/016，未作为可用 P1 接口。
  PTC／任务／Skill 等必要契约或测试依赖的存在不表示其产品能力启用。
- 上游 Provider 的匿名用户身份回调改为可选，产品不配置它；其余 Loop、Session 源码保持来源摘要。
  包清单与 TS references 按实际闭包收敛。原始摘要、当前摘要与原因保存在迁移登记，
  行为源码差异另保存于 [本地补丁](../../provenance/dsh-p1-local.patch)。
- 指令发现增加可选的 `projectRootBoundary`：产品只在已授权工作区内向上查找，
  没有 Git 标记时仍可运行，子目录继续继承工作区根约束；未配置时保留上游行为。
  独立空目录复现了原问题，新增回归覆盖中文／空格目录、子目录继承与外部指令不泄漏。
- Host 数据目录即使放在工作区内也不因此获得文件工具授权；只向实际执行所属会话开放
  其 Spill 目录。回归以嵌套在 `.runtime` 的真实 Host 验证配置读取拒绝、本人产物可读和跨会话拒绝。
- TZ-014 移除未启用的跨会话引用／查询、子 Agent、标题等非必要候选，保留实际测试依赖。
  早先 RUN 的迁入数是各步骤历史快照，以最终登记为当前闭包。

## 回滚与限制

本批代码回滚点为本地 P0 提交 `156569a32bca30055faff609958a611ca6285317`。
回滚前停止 Host、复制保存整个产品目录，再回退本批提交；P0 没有 P1 Session Reader，
应使用新的隔离产品目录启动，不删除或让 P0 原地改写 P1 日志。
Session 数据版本与产品配置版本独立，来源日志保留，不就地覆盖历史文件。

没有运行真实外部模型、真实客户端 UI／Connection、远程 CI，
没有验收 Windows/Linux/移动端安装、浏览器接管或通知送达。
本批通过的是 P1 本机核心出口；P2 及后续能力继续按计划实施。
