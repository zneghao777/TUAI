## 实现合同

三个新增产品包分别承担持久执行、外部连接和领域策略：

- `packages/product/task-runtime`：业务 SQLite、幂等请求、执行租约、fencing、审计和恢复 outbox。
- `packages/product/ego-connector`：已安装 Ego 的独立执行进程、随机受限套接字、结构化观察、PNG、输入和原生控制接口。
- `packages/product/browser-service`：资源身份、严格输入校验、控制权、当前证据、批准、未知结果、产物及限额。

Host 将浏览器工具接入既有 DSH；Reviewer 使用当前模型的统一 `llm.stream` 与计量。
等待时暂停原 Goal/Agent；明确归还后重新观察，通过同一 Session/GoalDriver 继续，
不另建浏览器 Agent Loop。持久唤醒消息有稳定身份，Session 落盘后才确认投递。

媒体与输入复用 Host Connection 的 owner、Origin 和 Session 授权，使用二进制
WebSocket；URL 无长期凭据。Renderer 不获得 Node、Shell、CDP、Profile 或 Ego 端口。
人工输入另绑定连接、peer、页面、epoch、viewport 和单调序号；失联保留人控，
不自动归还。收起只释放视图，不关闭任务页面。

最终工具 guard 在活动浏览器任务内阻止 Shell、网络、MCP、Skill、CLI 和批处理旁路。
普通聊天原有权限保持原样；这不是对整个操作系统的沙箱声明。

外部写入由当前证据和 Reviewer 判定，不使用金额阈值、按钮单词或 URL 分类。
具体批准绑定事务版本、摘要、身份、页面指纹、epoch 和 120 秒有效期。
提交前持久化意图；派发回执不等于商户受理、付款或出票。未知结果禁止再次提交、
直接人工输入及转入原生人控，只允许只读核验或停止任务。

当前支持个人 Host 的单个 owner 使用已授权的本机 Ego。`profileGrantId` 是连接授权，
不代表已识别网站账号或提供独立 Profile 选择。跨网站账号隔离仍待单独验收。
来源、版本、授权边界、文件保留和回滚见 [P4 来源记录](../migration/P4-Ego来源与运行边界.md)。

### 提交未知结果

受控站模拟“订单已接收、HTTP 回执丢失”，验收启动器另模拟 SDK 派发成功后 Host
未取得提交回执。真实链路依次经过具体批准、unknown、只读订单查询、证据核验。
站点只有一次提交按钮点击和一笔测试订单，结果为 reserved、未付款、未出票。

Chromium 在连接被关闭后会自行重试该 POST，测试观察到一次按钮点击对应多次
HTTP 尝试。站点按 intent 去重；本系统不承诺任意商户“一次 HTTP”或 exactly-once。
没有可用的商户幂等身份时，保留未知状态并只读核验，不能通过重试制造确定性。

领域测试另覆盖过期批准、页面变化、重复确认、双视图 CAS、旧租约晚到回执、
Host 重建后的未决意图、未知结果人工输入拦截，以及取消不等于退款/撤单。
实际重载验收 Host 后，同一 Task／Execution／Ego 空间及原生人控保持，未产生自动唤醒。
这些检查不替代真实 Ego 进程崩溃、系统休眠或外部支付验收。

### 输入与画面实测

真实 Ego、正式聊天侧栏、受控网页，持续 **60,519ms / 220 次输入**。
页面在实际 input 事件中改变固定小块颜色，使用 Canvas 像素变化测量实际页面响应。

| 指标                       | 结果                                                    |
| -------------------------- | ------------------------------------------------------- |
| UI 打开到首帧              | 1825ms                                                  |
| 输入到回执 P95             | 7ms，预算 ≤50ms                                         |
| Ego 采集到 Canvas 绘制 P95 | 30.57ms，预算 ≤80ms                                     |
| 输入到实际页面像素变化 P95 | 58ms，独立测量，不由两段延迟相加                        |
| 输入期间观测帧率           | 约 4.99fps / 302 帧；按页面变化取帧，不是视频刷新率承诺 |
| Host RSS                   | 202,440,704 → 185,712,640 bytes                         |
| Renderer JS heap           | 38,661,524 → 29,337,621 bytes                           |
| 队列上限                   | 媒体 1 帧在途 + 1 帧待发，解码 1 帧待处理，输入 128 个  |

Ego 已运行；此处测的是新连接器和新 UI，不是系统/Ego 冷启动。RSS 与 JS heap
是两端样本，不覆盖整个 Ego、GPU 和系统内存，也不能证明长时间没有泄漏。
原始数值见 `reports/p4/performance.json`。没有把这些数值当作物理屏幕扫描或实体 IME 延迟。

### 验收中修复的问题

- Ego Snapshot 没有稳定提供 checkbox 状态；补充只读语义状态，重复勾选不再反转。
- Enter、macOS 全选、双击计数及 IME 焦点代理按真实输入回执调整。
- Session 在无生命周期变化的通知中产生新快照，导致 React 更新循环；修复引用稳定性，
  保留真实 running、子会话地址和父会话可用性变化，迁移补丁记录在 M3。
- 未知结果不会因为再次接管而恢复写入权限；原生交接入口同样受限。
- 窄屏默认原始尺寸滚动查看，保留适合窗口切换；浏览器标题使用 DSH 已有的实时标题插槽。
- 截图派发后租约失效时清理未发布文件；错误只返回稳定代码，不回传可能含输入值的 SDK 消息。
- 剪切先取得本地剪贴板写入许可，再按选区摘要删除；无许可、空选区或选区变化不删字。
- Host 关闭时等待媒体释放；晚到回调不再访问已卸载服务或关闭的数据库。
- 原生人控重启后不自动抢回；可停止任务并保留 Ego 中用户控制的页面。
