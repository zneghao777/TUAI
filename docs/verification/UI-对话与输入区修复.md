## 实现边界

复用已有主题文件和组件，不修改参考仓库、迁入包、模型循环、工具执行、
权限与审批协议，也不新增依赖。

主要改动如下：

- [入口样式](../../apps/web/src/main.tsx)：补齐 DSH 字体、层级与高亮配色。
- [产品主题适配](../../apps/web/src/chat-theme.css)：统一宽度、字号、气泡和状态颜色。
- [布局样式](../../apps/web/src/App.module.css)：输入框、工具栏、附件、队列及审批卡的排版。
- [输入组件](../../apps/web/src/components/Composer.tsx)：内容自适应高度、精简提示，保留发送、排队、插话、停止、重试、草稿和上传行为。
- [交互卡](../../apps/web/src/components/Interactions.tsx)：整理审批、问题与队列操作布局，保持原业务回调。
- [新增回归](../../tests/p2/browser/chat-layout.spec.ts)：覆盖代码高亮、宽表格、字体、输入框伸缩与窄屏布局。

界面减少可见说明，同时保留按钮可访问名称、上传状态与稳定的组件标记，
便于键盘、辅助技术和浏览器 Agent 操作。相关上传测试改查真实就绪状态，
不再依赖已删除的重复文案。

## Codex 参考图输入区调整

2026-10-28，继续按用户提供的 Codex 截图调整输入区。下面的布局取代
前述工具栏分组，仍不修改总开发计划和阶段状态。

- 模型入口左侧显示上下文用量圆环，点击查看已用 Token 与上下文总长度。
  数据来自现有 `contextPressure` 投影；尚无数据时不伪造进度。
- 左侧权限改为菜单，复用 Host 权限目录和现有 `/permission` 命令。
  菜单内保留权限影响，默认仍由 Host 决定，不自动扩大权限。
- 右侧合并模型与推理控制：上方模型名称进入具体模型列表，下方滑块
  选择该模型实际支持的推理档位，可恢复默认值。不支持推理时隐藏滑块。
- 根据后续参考图，默认入口直接显示“模型名称 + 推理强度”，去掉闪电图标
  与常驻胶囊底色。输入框、按钮与弹层缩小，模型弹层宽度从 340px 调整到
  280px；窄屏权限保留图标入口，菜单仍展示完整选项。
- 发送位置只保留向上箭头，执行期间的停止与插话移到输入卡上方的操作行；
  排队、快捷键、草稿、附件、失败重试和请求去重行为保留。
- 输入框不支持手动调整尺寸，宽度随主区域适配，长草稿自动增高并在上限后
  内部滚动。输入区上缘添加 24px 渐进模糊，取消输入卡上方的额外间距，
  过渡层贴合输入框上沿，不截获点击与滚动。
- 浮层支持键盘、点击外部关闭和 Escape 返回焦点；模型列表与推理面板
  切换后保持焦点，窄屏按视口定位，320px 下不出现横向溢出。

新增 [输入区控制组件](../../apps/web/src/components/ComposerControls.tsx) 与
[局部样式](../../apps/web/src/components/ComposerControls.module.css)，复用已有浮层
定位与外部点击处理。全局表单样式排除原生 `range`，避免滑块被输入框背景覆盖。
没有新增依赖，也没有更改服务端模型、权限或工具执行协议。

[新增交互回归](../../tests/p2/browser/composer-controls.spec.ts) 使用隔离的真实 Host
与受控模型，验证档位持久化、实际模型请求参数、模型切换、权限命令、审批、
上下文数值、键盘焦点、尺寸自适应和模糊层事件穿透。测试提供商的额外模型与
推理档位只在 `composerControls` fixture 选项开启时存在，不进入产品启动路径。

## 权限菜单与上下文用量浮层

按用户最后两张参考图继续调整，并按用户要求合并提交本会话的 UI 改动。
总开发计划和阶段验收状态保持原样。

- 权限菜单宽度从 320px 缩到 250px，缩小选项间距和说明字号，桌面实测
  为 250 × 149px。通过共享选择组件的 `compact` 变体实现，其他下拉框保持原尺寸。
- 上下文浮层按 DSH 的层级展示“上下文已用 + 百分比”、`~已用 / 总长度`、
  分段进度条，以及系统提示词、工具定义、对话消息三行近似用量。浮层尺寸为
  264 × 144px；模型入口左侧的圆环同时显示百分比。
- 总量继续读取 `contextPressure`，分项读取现有 `contextBreakdown`；按 DSH
  的规则将分项比例映射到已用部分，不用分项估算值之和替换总用量。
  用 `~` 表示近似值，采用 K/M 紧凑格式；0% 时不绘制虚假的彩色占用段。
- 初次无数据、刷新恢复、三类颜色和窄屏浮层均保留可访问名称、语义化
  数据行及 Escape 返回焦点，不修改服务端统计或权限协议。

新增用例验证真实 Host 的投影数值与三项构成、非零分段占比、刷新后不发起
新模型调用；受控提供商用 `contextUsage` 选项提供测试用量，产品启动不使用。
