# TZ-077：晨曦主题验收

2026-10-29，在 macOS arm64、Node 26.8.1、Chrome 上完成本机定向验收。
范围见[晨曦主题需求](../specs/appendices/P2-晨曦主题需求.md)。

## 实现

晨曦作为产品配色扩展现有 `ui-theme` 设置域，不修改迁入 DSH 的主题服务。

- `ProductAppearanceSchema` 在原设置上增加 `palette: forest | dawn`，旧文档默认青绿。
- 选择晨曦将配色和浅色偏好一次保存，Host 拒绝非法值及不支持的明暗组合。
- 产品复用 Settings Controller／ConfigForm，没有增加浏览器本地偏好库。
- 设置使用 HeroUI Button，提供明确名称、`aria-pressed`、保存中禁用和失败提示。
  产品 Slot 替换原外观行，字体及其他显示设置继续复用原实现。
- 首屏注入和客户端持续同步均读取同一 Host 文档。共享语义变量统一
  HeroUI／DSH、侧栏光色、用户消息、菜单、输入区及代码表面。
- 原青绿浅色、深色和跟随系统行为保留。晨曦暂仅支持浅色；返回青绿可重新选择明暗。
