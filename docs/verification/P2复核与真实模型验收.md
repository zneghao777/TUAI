## 实现与凭据边界

前端设置通过现有鉴权 Gateway 和生成的 Typert codec 访问 Host。
`ModelManager` 负责提供商配置，推理仍由迁入的 DSH DeepSeek adapter、
Agent Loop 和 Session 执行。

- DeepSeek 官方提供商可保存或更换 API Key、测试连接和移除本地配置。
- 自定义提供商可管理标识、名称、地址、模型 ID、显示名和上下文/输出上限。
  当前协议为 DeepSeek Messages；没有伪装成已实现的 OpenAI 通用适配器。
- 非敏感配置保存为 `config/model-providers.json`；密钥保存为独立加密文件。
  本机包装密钥和密文均验证 `0600`，使用 AES-256-GCM 检测篡改。
- 已保存密钥不回传到网页，不写入 localStorage、源码、文档、fixture 或报告。
  显式 Host 环境引用作为后备；官方 API 地址固定为官方地址。
- 更换自定义地址时必须重新输入密钥；旧地址的密钥不能自动用于新地址。
  配置修订号防止旧窗口覆盖；删除后适配器和凭据同步撤销。
- 已通过保存后生效、重启恢复、并发旧版本拒绝、未认证请求拒绝、
  过宽文件权限、密文篡改和包装密钥丢失的定向测试。

新增包依赖只引用仓库已存在的 `dsh-llm-deepseek`、`dsh-atomic-write`
和已锁定的 `zod@4.4.3`，分别用于复用模型适配器、原子文件写入与外部配置校验。
没有引入第二份核心依赖或新的模型循环。

## 真实 DeepSeek 测试

调用官方 `https://api.deepseek.com/anthropic`，使用 `deepseek-flash`，
界面目录显示 DeepSeek-V4.1-Flash。官方接口与模型名称另核对了
[DeepSeek 文档](https://api-docs.deepseek.com/api/responses)。
用户提供的密钥只写入本机 Host 加密存储，不在本记录中保存。

| 案例                                           | 实际结果                                                                     |
| ---------------------------------------------- | ---------------------------------------------------------------------------- |
| Host 测试连接                                  | 有效 Messages 回复；首次探测约 213 ms，界面再次探测约 0.2 秒                 |
| 第一轮：记住“青松七号”，调用工具计算 137 + 268 | 实际 `sum_numbers` 参数为 137、268；工具返回 405；模型中文回复包含代号和结果 |
| 第二轮：只回忆代号和结果，不再调用工具         | 回复“代号：青松七号；计算结果：405。”；没有第二次工具调用                    |
| 流式与持久化                                   | Session 中记录实际文本增量；两轮均以 `completed` 结束                        |
| 刷新恢复                                       | 两个最终文本回答与工具记录恢复，没有重复发送或重复回答                       |

关闭推理时，Host 从 `turn/start` 到结束分别为 **2070 ms**、**937 ms**；
到首次文本增量分别为 **1889 ms**、**813 ms**。第一轮包含一次工具调用、
两次模型请求，第二轮包含一次模型请求。这些是本机小样本的 Host 记录，
不是浏览器首屏耗时、通用性能承诺或复杂任务效果基准。
