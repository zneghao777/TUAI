## 产品适配与界面调整

1. 新会话通过原 Session Controller 的窄创建策略，在 Host data/workspaces 下生成独立目录并登记原 Workspace。客户端不接受自定义 cwd 或 workspaceId；普通界面不显示目录。
2. 分叉沿用 DSH 原语义，继续使用来源工作区，保留历史文件引用；已有会话 cwd 不搬迁，归档不删除目录或历史。空会话显示“新会话”，不回退到目录编号。
3. 原 Agent 指令加载增加可选 Session 根边界，产品显式启用；解决新目录不在 Host 启动 cwd 下导致指令读取失败的问题。默认上游配置不变。
4. 文件工具执行上下文通过 AsyncLocalStorage 传递；搜索同时检查预执行路径和最终 guard，不能跳过预检查直接执行。权限标记读取 Session 实际投影。
5. 左下角改为“设置”，集中模型和原 DSH 对话显示偏好；原菜单与弹窗为不透明底色。移除右上角重命名、分叉、显示设置及连接／路径入口。
6. 会话行使用原 DSH 菜单和确认交互。活动会话归档须确认停止；取消保留运行，恢复不会自动重启已停止工作。复制 ID 失败明确提示。
7. 用量按钮、统计栏及显示开关暂隐藏；真实统计、日志与协议保留。思考过程、工具详情和整轮耗时继续显示。

侧栏容器仍由产品组合，完整原侧栏布局、排序、内容检索和消息位置分支属于 TZ-068。
当前菜单与归档子集提前交付，不将 TZ-068 或 TZ-067 整项标为完成。

## 权限与 Web 事实边界

文件、Shell、终端共用原 SandboxPolicy。现有 Profile 默认只读且 Shell 逐次审批，
旧批准、过期、取消和最终 guard 继续有效；workspace-write 和 full-access 执行层已接通。
四项权限选择、Auto、新安装默认值由 TZ-066 完成，本项不自动扩大历史会话权限。

文件 API 的 Host 私有目录检查不等于整机进程隔离。原 Shell 沙箱限制写入，
并不隔离其他可读文件；完全权限会解除其文件修改限制。终端和 Job ID 的跨会话操作已验证拒绝。

当前锁定的原 HTTP Fetch 允许 localhost／私有地址，源码测试也明确覆盖成功访问。
保留 HTTP(S)、禁止 URL 凭据、同源重定向、响应大小及超时限制；它不是 SSRF 防护实现。
截图中的非公网地址拒绝不能替代本基线源码事实。测试分别验证真实 URL 拒绝和网络失败，
不把连接失败算作权限拦截，不用 Shell 绕过抓取错误。
