# P2：纯白默认主题

2026-10-29 用户确认新增「纯白」并作为新用户默认配色，保留青绿和晨曦，
不覆盖已有用户选择。对应 TZ-082，依赖 TZ-077 的 Host 设置与主题适配。

## 配色与材质

纯白先提供浅色版，复用已有布局和 HeroUI／DSH 语义变量。

| 角色 | 色值／行为 |
| --- | --- |
| 阅读画布 | `#FFFFFF`，正文、代码及工具输出保持清晰 |
| 侧栏底色 | `#F6F7F9`，叠加约 80% 白色玻璃 |
| 次级表面与选中底色 | `#EEF0F3` |
| 正文／次要文字 | `#24272E`／`#626873` |
| 主操作 | `#272B32`，白色文字与图标 |
| 分隔线 | `rgba(35,39,46,0.08)` |
| 输入框 | 约 90% 白色，18～24px 背景模糊、白色内高光与轻接触阴影 |
| 浮层与设置 | 更高不透明度；保留焦点、成功、警告、错误语义 |

链接和键盘焦点采用克制的灰蓝色。鼠标柔光保持中性、低强度，
触屏及减少动态效果时继续禁用。无需新增装饰标语或默认主题标签。

## 设置与兼容

选择和兼容都由现有 `ui-theme` Host 文档管理，不新增本地缓存。

- 设置提供「纯白」「青绿」「晨曦」，明确 `aria-pressed`、禁用和保存失败状态。
- 全新或空的主题设置默认纯白浅色；首屏注入与客户端使用相同配色。
- 已显式保存的青绿、晨曦和其明暗、字体设置保持原值。
- 旧非空主题文档没有 `palette` 时，在读取时推断为青绿，不写回文件，
  不增加修订号；下次用户主动保存时连同推断结果保存。
- 新用户只修改字体时也保存当前纯白配色，重启后不得误判为旧青绿。
- 纯白与晨曦仅浅色；主动选中它们时将配色和浅色原子提交。
  青绿继续支持浅色、深色、跟随系统。
- 保存失败保持上次确认的配色、草稿和会话；支持重试，非法组合和过期修订被拒绝。
