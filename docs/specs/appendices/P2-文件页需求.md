# 文件页需求

## 2026-10-30 右侧工作区与会话产物

右侧新标签页并列提供工作区文件与会话产物入口，不在文件树工具栏放置产物跳转。
工作区文件树只浏览当前会话的工作区，按层级左对齐、提供展开指示，保留刷新、文件预览和下载。
会话产物继续读取当前会话附件与完整工具输出，分类展示并提供下载；空、加载和失败状态互不混淆。
支持安全预览图片及有界文本，不支持或过大的文件仍可下载。左侧跨会话文件页的数据范围不变。
验收覆盖入口、目录层级、文件预览、附件与工具输出分类、下载、失败重试、会话隔离、键盘与主题。

2026-10-29，用户确认在“我的 BOT”后新增文件入口，汇总会话产生的文档和图片，
以及用户在聊天中发送的图片附件。
页面保留现有主题，文档与图片严格分类，仅使用网格卡片；排序入口是图标按钮。

## 交互

- 使用项目现有导航、主题变量及 HeroUI 组件；支持分类与卡片预览。按用户最新要求，文件页不提供搜索。
- 图片卡片只展示缩略图，不在图片下方显示名称或来源；保留可访问的图片名称。
  图片预览采用全屏深色背景，支持关闭、切换、下载，并复用删除确认。
- 提供创建时间、标题、最近打开时间排序，数据缺失时不得编造。排序菜单复用权限选择的紧凑样式，选项不加图标。
- 选择模式提供全选、取消和批量删除，切换分类清除选择。“选择”和“全选”采用轻毛玻璃按钮。
- 删除会永久删除所选生成文件的工作区原文件；确认框明确说明不可恢复，逐项反馈失败。
  用户发送的图片只从文件页移除，会话消息仍引用的附件保留。
- 展示来源会话；无内容、加载失败、文件不存在和无法预览均提供明确状态。

## 数据与验收

现有会话产物接口仅覆盖消息中的附件及部分工具输出，不能证明工作区内文件
均由会话产生。文件页需要 Host 持久化可追溯的产物身份、来源和生命周期；
历史文件只在有可验证来源时收录，不把任意工作区文件当成会话产物。
除成功的 `write` 创建记录外，Agent 可通过只读的产物登记工具显式登记
其交付的文档或图片；登记证明会话声明了该工作区文件，不证明文件由哪个进程创建。
未登记的历史 Shell 文件不可推断归属，不能宣称已全部收录。
用户已发送消息中的图片按持久化的附件引用登记，包括可读取的历史消息；
未发送的草稿附件不进入文件页。附件复用会话鉴权的产物读取链路。
工作区文件和附件的读取、预览、删除分别遵循现有授权和共享关系；不直接
删除被会话引用的附件。预览复用现有渲染能力，扩展名不代表预览成功。

验收覆盖真实 Host 下的跨会话产物发现、新旧文件、权限、分类、卡片预览、
排序、选择、删除、部分失败和重启恢复；还需验证桌面、窄屏、主题、
键盘操作及既有会话、右侧文件预览和附件访问不回退。验证用户发送图片的
登记、历史恢复、预览和文件页移除后聊天图片仍可访问。
