# P2：晨曦主题与配色切换

2026-10-29 用户确认新增「晨曦」浅色主题，保留现有青绿主题。

后续默认值与三种配色兼容规则由[纯白主题需求](P2-纯白主题需求.md)补充；
下文默认青绿描述保留为 TZ-077 的历史基线。
本项对应总计划 TZ-077，独立于仍在进行的聊天导航简化。

## 范围与行为

配色使用冷白画布、白色内容、淡青紫边缘光和蓝色操作，适合长对话阅读。

- 设置中的配色提供「青绿」「晨曦」，默认沿用青绿，旧设置无需迁移。
- 复用现有 `ui-theme` Host 设置域，新增 `palette`，与明暗偏好分开保存。
- 选择晨曦时将配色和浅色偏好原子保存；晨曦暂不支持深色或跟随系统。
  返回青绿后恢复原有浅色、深色和跟随系统选择。
- 保存成功后更新颜色；保存失败保留 Host 已确认的选择，并提供可重试错误。
  刷新、重新连接和重启 Host 从持久设置恢复，不依赖浏览器本地存储。
- HeroUI 与 DSH 复用语义变量；正文与工具输出保持清晰，玻璃用于输入和少量浮层。
  光效不拦截输入，保持触屏及减少动态效果的停用规则。
- 配色设置通过明确的按钮名称、选中状态及 Host 公共设置协议供用户和 Agent 访问。

## 色板与应用

下表定义浅色版的主要颜色角色，状态色保持既有含义。

| 角色 | 值 | 应用 |
| --- | --- | --- |
| 画布 | `#F5F8FC` | 工作台底色 |
| 内容 | `#FFFFFF` | 正文、代码、设置与菜单 |
| 主文字 | `#1E293B` | 正文与标题 |
| 次级文字 | `#5E6F86` | 工具过程、说明与输入占位 |
| 主操作 | `#155DFC` | 发送、链接、焦点 |
| 按下 | `#124DCF` | 操作交互反馈 |
| 选中 | `#EAF3FF` | 用户消息、导航与选项 |
| 细边 | `#DDE6F2` | 输入与表面分界 |
| 淡青／淡紫 | `#EAF8FD`／`#F3EDFF` | 侧栏及边缘光感 |
