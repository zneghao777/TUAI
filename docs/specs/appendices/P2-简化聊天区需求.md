## 范围与依赖

侧栏按最近活动平铺会话，置顶排在前面。移除工作区分组、分组方式、排序／筛选、复制 Session ID、分叉和归档列表入口及对应快捷键；保留新建、打开、置顶、重命名与归档，增加独立删除确认。收起侧栏和窄屏仍可新建、打开聊天。手机宽度展开侧栏时显示完整导航，暂时隐藏聊天内容和拖动条，避免将聊天区挤成窄条；打开会话后收起导航，恢复聊天宽度。

每次新建聊天由 Host 创建独立工作目录，前端不显示目录或工作区分组。macOS 为 `~/Library/Application Support/TUAI/data/workspaces/<会话ID>`；Windows 为 `%APPDATA%\TUAI\data\workspaces\<会话ID>`；Linux 为 `${XDG_DATA_HOME:-~/.local/share}/TUAI/workspaces/<会话ID>`。设置 `TUAI_HOME` 后统一使用 `<TUAI_HOME>/data/workspaces/<会话ID>`。已有旧数据目录继续兼容。目录位于 Host 所在设备。

删除是 Host 持久化的独立标记，不等同归档。删除后列表、搜索和资源访问不再接纳该会话，阻止继续运行；刷新、重连和重启后仍生效。为避免误删用户文件，工作区目录及底层日志保留，确认框明确说明。正在运行时先确认停止并删除；失败显示真实错误，不能显示假成功。后续设置内的归档列表本次不做。

权限目录、默认设置及 `/permission` 仅提供“仅可查看”和“完全权限”。新 Host 默认仅可查看；旧配置 `workspace-write` 回落到只读，已有会话不自动扩权。完全权限保持现有确认。完成状态左对齐；思考文案为“正在思考”；输入占位为“与 TUAI 对话”。
