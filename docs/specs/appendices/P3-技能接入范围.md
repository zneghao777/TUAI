# P3 技能接入范围

2026-10-29，用户最终确认本轮仅实现 Skill，不扩展其他 P3 页面或其领域服务。
本文件细化 TZ-031 的独立能力和 TZ-032 的技能界面验收，保留原任务全部历史要求。

## 本轮交付

1. 从用户选择的 SKILL.md 或技能目录导入包，Host 校验结构、路径和大小；不执行安装脚本。
2. 保存不可变版本、文件摘要、导入来源、结构检查结果和个人使用范围。
3. 支持编辑生成草稿版本、结构检查、启用、停用及回滚已检查的历史版本。
4. 将有效版本接入 DSH Skill 注册表及原有 skill 工具、用户显式调用机制。
5. 一次会话回合锁定技能版本；实际加载记录版本与摘要。停用后拒绝新的加载，
   已进入上下文的知识无法撤回，后续工具操作仍受原有权限控制。
6. 技能页提供搜索、状态筛选、内容／文件／版本查看及在聊天中使用；输入框补全技能。
7. 使用现有 DSH 组件适配层与语义主题，不修改文件页、模型设置和既有聊天布局。

## 依赖和边界

- 当前没有长期 AgentDefinition、群聊或产品 TaskExecution。本轮不创建替代身份，
  个人范围以当前已认证单 Host 所有者为边界；Agent／群绑定及 Execution 级锁定
  保留在 TZ-031 的未完成依赖中。
- 结构检查只证明包格式、资源和声明完整，不表示业务操作或网站能力经过验证。
- 不实现 P5 自动学习、泛化评测或学习质量指标。
- 管理 API 使用独立的 skillLibrary Remote，沿用现有 Gateway 鉴权与 Typert codec；
  保留 DSH skills/list 的会话候选目录语义。
- 产品数据保存在 Host 的业务目录，与 Session 日志和产物分开；源文件导入后
  不依赖开发机绝对路径。配套文件按需经技能资源工具读取，不放开 Host 私有目录。

## 验收

覆盖导入、格式错误、重复名称、越界文件名、版本冲突、重启恢复、编辑与回滚、
停用失效、回合内版本稳定、资源读取、显式与模型调用、工具权限不扩大、
真实 Host RPC、三主题、窄屏与键盘操作。受控模型证明实际 Loop／工具链接入，
不代替外部模型选择技能的质量评测。

TZ-031 和 TZ-032 仅按实际完成步骤登记；Agent／群绑定、持久协作等原始验收
未完成前，不标记两个总任务或整个 P3 已完成。
