## Visual Theme & Atmosphere
明亮、专业、简洁、圆润、精致。保留 DSH 的空间秩序：左侧窄导航；主页中央聚焦输入；聊天以可读消息流为主。不是运营后台、开发者控制台或营销页。
整体浅色（浅色面积超过90%），不采用任何深色侧栏/顶栏/输入框。圆润轮廓、轻盈磨砂玻璃层次、舒适留白；不靠大卡片堆砌信息。

## Color Palette & Roles
珍珠白底 #F5F6F8；浅雾层 #EDF0F4；磨砂白表面 rgba(255,255,255,.68–.82)；石墨正文 #282D35；次级文字 #717783；细边 rgba(255,255,255,.92) 与 rgba(49,61,80,.07) 双层组合。
一个低饱和雾蓝强调色 #536985，按下 #445A75，用于发送、选中与焦点。减少偏蓝灰的整片填色，保持大面积中性的珍珠白；极淡灰蓝光线只服务玻璃透光层次。
主要文字内容区域使用近实色表面，保证对比。玻璃用 backdrop-filter: blur(24px) saturate(110%)，组合1px内高光、极淡中性灰接触阴影与大范围低透明度漫反射阴影。避免白色背景叠白色卡片导致玻璃不可感知，也避免厚描边、强蓝光和塑料感。

## Typography Rules
中文 PingFang SC / Noto Sans SC，西文 Geist 或同风格现代无衬线。正文15–16px，辅助文字12–13px，首页问候24–28px。代码只在用户展开工具详情时使用等宽字体。不使用大段全等宽正文。

## Component Stylings
主输入框24px圆角，玻璃侧栏20px，按钮12–16px，历史行12px，弹层18px；统一细描边、轻阴影。主体消息不用一条一张厚边卡片。图标使用统一细线图标，不用emoji。
侧栏、输入区、悬浮菜单体现毛玻璃；正文安静清晰。hover轻微提亮/上移1px；按下缩至.985。权限/模型只各出现一处。

## Layout Principles
DSH式简洁会话壳：约236–252px左栏，主要内容宽720–820px。首页聚焦一个输入区与极少的示例提示；聊天以消息流为主体，工具详情渐进展开，来源/产物按需抽屉。不要永久占一整列的密集调试面板。
窄屏导航按需打开，输入和停止保持可用。当前P2不加入独立知识库、Agent、插件、计划、浏览器接管模块。

## Motion & Interaction
必须在输出的HTML原型里实现，不能只有静态标签：
1. 保留系统鼠标指针。在主要空白画布中增加直径约180–240px、极低透明度的浅灰蓝柔光，缓动跟随鼠标；靠近磨砂输入框时有微弱玻璃反光。图层pointer-events:none，文字与按钮不被遮挡，不做拖尾粒子或彩虹。
2. 悬停按钮/历史项160–200ms；点击有轻微按压；输入聚焦描边渐亮。
3. 侧栏/详情面板进入180–240ms，采用opacity和transform；列表只首次进入轻微错峰。不要无意义持续跳动。
4. 运行中只有轻微状态点/流式光标；鼠标离开时光晕渐隐。使用requestAnimationFrame合并pointermove，不每次mousemove触发布局。
5. prefers-reduced-motion及触摸设备关闭鼠标光晕与位移动效。不自动播放大段动画。
截图自然呈现玻璃高光即可，不画示意鼠标/箭头来冒充动态。

## Anti-Patterns
禁止深色底、超大标题、企业后台、厚重面板、多个高饱和色、复杂渐变背景、三张等宽功能卡。
禁止虚构版本、token/费用统计、会话ID、系统路径、临时缓存路径、网络隔离说明、本地宿主状态、“所有数据仅本地”的承诺。
模型、文件与历史内容只是设计演示，不代表真实运行。必要功能保留，布局和细节由Stitch在上述方向内完整设计。

### 工具调用展开

消息内展示工具名、操作对象、关键参数、输出和嵌套记录，支持参数/输出切换与收起。
状态预览包含运行中、成功、读取失败；失败时不继续展示成功输出。
重试入口限定为只读步骤，不重发整轮任务。复制按钮实际尝试写入剪贴板，
失败时显示反馈。耗时、页码、文件和工具名均为设计演示，不是本项目执行证据。

### 等待审批

审批卡完整展示操作、目标、范围、原因和待写入内容，批准/拒绝/取消按钮不得被输入框覆盖。
只提供“仅允许本次”，不预建永久扩权选项；原草稿保留且可编辑。

| 状态 | 呈现与行为 |
| --- | --- |
| 待审批 | 明确等待用户决定，发送禁用并解释原因 |
| 提交中 | 三个决定按钮禁用，避免重复提交 |
| 已批准 | 显示等待执行端继续，不将批准当作文件写入成功 |
| 已拒绝 | 明确未执行本次写入 |
| 已取消 | 明确本次任务已取消，尚未执行此写入 |
| 已失效 | 旧批准按钮禁用；刷新仅查询最新状态，不重新激活旧授权 |

原型的“待审批/审批过期/状态重置”仅用于设计评审，真实产品状态必须来自 Host。

### 消息排队

运行中的追加需求提供“排队发送”和“立即插话”两个不同动作。
排队项支持内联编辑、保存、取消、移除和空队列；取用后从待处理队列移出，不能再编辑。
插话回执只表示已接受、等待采纳，不表示已执行。空输入不可发送，提交后清空草稿并禁用空发送。
停止过程显示“停止中→已停止”；已有副作用不因此撤销，队列不会被假装已处理。
“取用首项/清空队列/重置”是原型演示控件，不直接成为产品需求。
原型支持 Enter 排队、Shift+Enter 换行、Cmd/Ctrl+Enter 插话，中文组合输入不触发发送；
实际产品快捷键仍按实施时的契约核对。

### 异常恢复

错误按来源显示，不能统一变成“重新发送”。已接受但结果未知的请求先核对状态，
有副作用的操作不盲目重做。

| 子状态 | 入口与恢复语义 |
| --- | --- |
| 连接中断 | 左栏/顶栏状态一致；消息及草稿保留，发送禁用 |
| 重连中 | 重连按钮禁用，先核对会话最新状态 |
| 已恢复 | 更新同一条回答并继续接收更新，不追加重复回答或重发旧请求 |
| 模型暂不可用 | 查看原因、选择已配置的备用模型；更换模型不自动重发 |
| 只读工具失败 | 检查文件、重试本步骤，不重做整个任务 |
| 附件上传失败 | 重试上传或移除，文字草稿保留；上传成功不等于消息已发送 |
| 审批已失效 | 旧决定禁用，刷新状态不会自动批准 |

模型名称、备用模型、权限标签为原型占位，实施时必须使用 Host 允许的真实配置；
本轮视觉认可不改变现有权限设置或审批契约。

## 验证与后续边界

已查看四张新增状态 PNG，并修正审批操作被遮挡、断线状态矛盾及不实费用承诺。
在本机浏览器实际检查了：工具只读重试、队列编辑保存与消费、空队列、插话回执、
追加队列与空发送禁用、停止中/已停止；审批提交锁定、批准后等待继续、拒绝、
过期与刷新；断线恢复后左右状态一致、草稿保留、回答只出现一次；
模型选择不重发旧请求，以及附件重试的上传中/已上传状态。检查时四页没有浏览器脚本错误。

PNG 保留 Stitch 的最终视觉稿；本地 HTML 在其基础上补齐状态演示、语义一致性和
鼠标动效休眠。未连接真实模型、Host、文件写入或上传服务；这些演示不是产品联调、
权限验证或 P2 验收。HTML 依赖外部字体/图标与 Tailwind CDN。

等待用户问题、完整产物预览、历史分页、无模型配置、窄屏/软键盘和全套键盘无障碍
仍需对应设计与验收。本次仅补用户指定的四类交互，不将其扩大为 P2 全部完成。
