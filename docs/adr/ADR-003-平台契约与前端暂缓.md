# ADR-003：平台契约初稿，前端选型暂缓

用户于 2026-10-27 仅确认包名和目录策略，要求前端暂缓。
React、Vite、视觉方案、Electron 选型及客户端协议实现仍未冻结。

P0 已建立 Node-free 的 PlatformCapabilities、HostIdentity、HostPath 和
结构化 unavailable 契约。HostId 绑定路径，目录语义以 Host 操作系统为准。
远程客户端不能把 Host 路径解释为手机目录；当前 Web 适配器如实返回不可用。
真实目录选择、通知和桌面桥接留给后续阶段。

产品 Node 配置与凭据解析独立于 Client 包。Host 配置只保存凭据引用，
P0 仅提供显式环境变量解析器；尚未实现平台 Keychain 或加密磁盘凭据库。
解析后的密钥不会进入 Client projection、配置文件或启动日志。
不同存储适配器实现相同 CredentialResolver，后续实现无需改业务调用。

数据目录通过 TIANZHIAI_HOME 注入；否则 macOS 使用
`~/Library/Application Support/TIanZhiAi`，Windows 使用 `%APPDATA%/TIanZhiAi`，
Linux 使用 XDG config/data/state/cache 分域。目录分别管理业务库、Session、
产物、下载、浏览器 Profile、日志、缓存和临时文件。
P0 仅准备目录契约，没有创建业务库或浏览器 Profile 内容。

验证覆盖 Windows 路径纯函数、中文空格目录、Host 身份持久化、
跨 Host 路径拒绝、凭据缺失及敏感值不进入 Client。
macOS 上的路径测试不能替代 Windows 或移动端的真实安装验收。
